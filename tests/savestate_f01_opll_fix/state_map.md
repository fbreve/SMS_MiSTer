# F01 implementation contract, frozen before production changes

The table uses packed semantic source offsets for record fields, not raw backing-register offsets. Channel-register packing is `encoded22 = source[23:16] & source[13:0]`; raw bits15:14 have no consumer. Voice36 is AM35, PM34, EG33, KR32, ML31:28, KL27:26, TL25:20, WF19, FB18:16, AR15:12, DR11:8, SL7:4, RR3:0. Envelope25 is state24:23 plus phase22:0. SIGNED_LI10 is sign9 plus value8:0. The nine instrument-cache nibbles occupy increasing four-bit offsets in channel order. Baseline source line references identify the inventory source; current accessors add lines.

Acceptance edge T executes ordinary guest work using the old freeze signal. Collection begins at T+1: post-T scalar/pending-store controls accompany pre-commit backing arrays. Every ordinary writer stays inhibited until release. This pairing retains an outstanding array store exactly once. The private scan has 104 read/collect pairs (208 host edges); apply has 104 read/write pairs plus eight stationary cache-refill edges (216), excluding command/completion handoff. No xena tick is used for refill. Actual initialized readiness becomes high at edge115 after reset release; edge116 is the first eligible acceptance, after sweeps finish within114 edges.

32-bit synchronous local read/write; addresses below are private 32-bit rows. One 256x32 M10K scratch. Each read has one registered response; SAVE uses issue/collect edges. LOAD validates the complete descriptor, row padding and bounded fields before any live write. No variable barrel packer.

SAVE acceptance additionally requires all six initialization-ready signals. Each initializer progresses on host clocks even with xena=0; all complete within 114 rising edges after reset release. This gate delays acceptance, never freezes guest execution early. Normal acceptance conditions still apply. Both SAVE and LOAD preserve the pre-commit array representation from the first frozen edge. Ordinary stores and initializers remain inhibited during all collection, restore and refill. Eight stationary host edges refill pure caches; no attack/sine/guest tick.

The 37 initializer-control bits and 1296 fixed voice bits explicitly remain outside the payload only under this readiness contract. ModelSim uninitialized backing is not evidence of hardware power-up constants; readiness follows explicit RTL writes. Warm reset drops readiness immediately. Legacy LOAD resets OPLL locally and waits for readiness; it cannot reproduce absent historical FM.
