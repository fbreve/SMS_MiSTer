    Implement savestates and enhance detection for Zemina/Nemesis (#191)
    
    * Implement and stabilize savestates
    
    Implement savestate support for the SMS MiSTer core, ensuring cycle-accurate CPU state restoration and reliable memory recall.
    
    * Use CRC/header for Zemina/Nemesis detection
    
    This commit fix misdetection of Sonic The Hedeghog (both SMS and GG) mapper.
    
    Refactor Zemina/Nemesis mapper detection to rely on CRC/header signatures instead of write-based heuristics. Removed write-triggered signals and logic (mapper_zemina_det, auto_nemesis1_boot, detect_nemesis1/detect_nemesis2, rom_last_page_idx, rom_last_byte0, and related write paths) and add mapper_nemesis_auto and mapper_zemina_crc driven by rom_crc16_run and page-0 bytes. Nemesis I boot now maps $0000-$1FFF to the last ROM page when mapper_nemesis_auto is asserted, and plain-Zemina games are detected by explicit CRCs (9136, 599E, C47B, 880E). Simplified metadata capture to only track rom_size_pages and page-0 bytes, removed last-page tracking, and adjusted mapper_out packing and various detection-window checks (including Wonder Kid/4-PAK adjustments) accordingly. These changes reduce ambiguous detections and ensure correct startup mapping for known ROM edge cases.
    
    * Document BIOS loading and savestate behavior
    
    Update README: add "BIOS Loading Support" and "Savestates" to the feature list and clarify savestate persistence. Notes that regular ROM savestates are stored on the SD card while BIOS built-in games save to SDRAM (non-persistent), and provide a workaround to load the BIOS with an empty ROM.
    
    * Enhance savestate UI: gamepad combos & OSD info
    
    Expand savestate UI and integrate it with top-level SMS.sv. Updated CONF_STR to add OSD menu entries and save/load message indices. Wire new ss_info / ss_info_req / ss_status signals into hps_io and SMS, and push slot changes back to the OSD when the joystick combo updates the slot. Replace/extend savestate_ui with a richer implementation that supports PS/2 Alt+F1 save / F1 load, dedicated SaveState gamepad button combos (slot left/right, Pause+Up/Down for load/save), a hold-to-hint timer, info message indices, allow_ss gating, selected_slot output, and a one-cycle statusUpdate pulse to sync the OSD. Overall this improves gamepad-driven save/load UX and OSD feedback for savestates.
    
    * Fix regression bug in Astro Flash (Japan) - System E
    
    This bug was introduced in commit a2c0a09cebb92879c821ed39e68f9b0b126b4455
