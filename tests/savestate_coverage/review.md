# Functional savestate coverage audit

Audited 2026-10-20 at `8443a0d19a88aff7a5900011bccf386daf146945`. **Savestates are not functionally complete across the implemented feature set.** Production RTL was not changed. No commit, push, PR, Quartus build, optimization, or hardware test was performed.

The inventory contains **90 distinct semantic state groups**: **41 A** explicitly transferred, **2 B** indirectly represented, **2 C** reconstructed, **3 D** deliberately reinitialized/irrelevant, **9 E** external/configuration, **21 F** potential coverage-gap groups, and **12 G** groups requiring further proof. Thus 14 groups are reconstructed or justifiably excluded (C/D/E), with another two represented indirectly. Counts describe groups, not individual flip-flops or independent bugs. The 21 F rows consolidate into **16 finding families** below: three reproduced in simulation, ten confirmed by direct RTL dataflow, and three requiring accepted-boundary/reachability evidence. “Confirmed by dataflow” does not mean reproduced in a game.

`coverage_matrix.csv` records covered state as well as omissions, sizes, storage positions, save and load paths, rationale, risks, and test evidence. `declarations.csv` indexes 1,192 declarations across the top-level and RTL tree, including process variables, array types, combinational signals and unused alternatives. It is a discovery aid, not 1,192 individually proven state items. No claim of exhaustive flip-flop equivalence or exhaustive dynamic mode coverage is made. Unproven reconstruction is G rather than presumed complete.

## Scope and method

Started at `SMS.sv`, `files.qip`, and the nested T80, JT89 and VM2413 manifests, then followed instances through system, memory decode/bus, mapper/detection, Evolution, VDP/background/sprites/shifters/CRAM, IO/EEPROM, video, peripheral and host interfaces. The second VDP/PSG and all four System E VRAM halves were considered separately. Dead declarations and source-only alternatives were distinguished from instantiated state; QIP inclusion alone does not prove an instance exists. ROM, BIOS, decryption keys, cheat definitions and host settings are preconditions; they cannot be silently changed between save and load. Local link endpoint and emulated controller protocol state are not excluded merely because their inputs come from outside the console.

Read both packing and live restore assignments. Checked the accepted save boundary, capture timing, conditional paths, word/byte counts, restore strobes, ordering, and relevant free-running processes. Automated checks verify 36 direct VDP packing/unpacking fields (with boolean/control exceptions reviewed separately), CPU high-word width, and memory range arithmetic. Consult `static_checks.txt` for the actual checked count and results. These are source checks, not substitute RTL simulations.

Save acceptance requires raw CPU CE, normal M1/MREQ, unprefixed instruction set, VBlank and x<256 (`savestates.sv:831`). CPU snapshot is pre-tick; VDP/IO/video/mapper are captured on the following ARM edge. Freeze then drains DDRAM for 32 idle clocks; PSG is captured separately when quiescent. This is **not** a universal protocol boundary: EEPROM commands, controller phases, GG serial transfers and pending mapper launches can span instructions and frames.

On load the controller reads the header and snapshots, streams VRAM/WRAM, restores mapper/Evolution/EEPROM first, optionally streams NVRAM, applies CPU/VDP/PSG/IO/video, streams 32 CRAM entries while frozen, flushes pipelines, then releases on a quiet enable phase. A registered audio phase strobe applies at release. Separate clocks/edges matter: CPU/VDP enables stop, but several peripheral processes and AudioMix continue on clk_sys; PSG's divided enable is computed at the falling edge. The MiSTer presentation/transport clocks are not emulated CPU state.

## Positive transfer evidence and memory boundaries

* **CPU:** 230 bits, not the stale 212/229-bit comments. Words 002–005 preserve A/F and alternates, I/R/SP/PC, 128-bit general register bank, IM/IFFs, WZ, Alternate and HALT. Fourth word is 26 padding bits plus bits229:192. `RegDIR` reverses the Alternate-dependent bank permutation. DIRSet works with CEN=0 and resets instruction/bus context. Pending interrupts and exact microarchitectural restart remain separate findings/evidence obligations.
* **VDP:** both 128-bit control vectors have matching direct restore slices, including address/control latch, buffered VRAM data, GG CRAM partial-byte latch, line counter, IRQ/status flags and horizontal scroll latch. Bit103 reset_flags is deliberately cleared rather than restored. HCounter latch is absent. VRAM read/write edge pipelines and sprite/background reconstruction are not certified merely because register fields match.
* **CRAM:** each 32x12 array concatenates `entry*12+11:entry*12`, passes through six 64-bit words, and is restored with `cram_entry=0..31` using the same 12-bit slices. SS writes have priority over CPU writes. Registered read outputs refill from the restored array.
* **Mapper:** normal banks and RAM control/lock flags use matching word00f slices. Janggun uses four 6-bit bank + reverse-bit groups. 4PAK reg0 is indirectly bank0. System E substitutes F7 into low8 and avoids restoring that byte as normal bank0. Evolution substitutes its own mapper layout; its reserved upper64 output bits are zero and the operational low96 connection is intentional, not a lost 64-bit state record.
* **Media/IO:** bootloader_n restores before CPU; cartridge-disable is IO bit31, restored after mapper defaults. SC multicart page/PPI select and System E analog select/VDP+PSG enable settings have actual restore consumers. Unimplemented card/expansion bits are legitimately normalized.
* **PSG:** actual oscillator/noise state is transferred, not just replayed register writes; see dedicated section below.

All addresses below are **64-bit DDRAM word offsets**, inclusive. Header size counts 32-bit words, while slot address arithmetic uses 64-bit words. A 0x3000-word slot is 98,304 bytes (96 KiB), not the stale top comment's initial 0x10000 stride. Actual base functions use 0x3000 stride; BIOS slots follow four cartridge slots and are DDRAM-only.

Current streaming pushes sequential bytes into the high end of the buffer and shifts right; after eight visits byte0 occupies low8. Restore uses low byte first. The eighth-byte stall latch preserves the first byte observed while DDRAM is busy. Termination tests are inclusive and restore counts match the source ranges; no arithmetic off-by-one was found. System E takes its VRAM2 route instead of NVRAM, so those mutually exclusive regions overlapping in address space is intentional. However, **selection of which NVRAM to transfer is incomplete**. Range arithmetic does not establish correct data at every address under randomized RAM latency; that integrated transfer regression remains required. Old-format loads deliberately avoid reading formerly unwritten NVRAM and cannot recover information never present in old files.

## PSG fix assessment

**The recent fix preserves the implementation's substantive PSG state and passes the targeted replay in this audit.** It saves configuration plus three tone count/polarity pairs, raw signed9-bit channel volume outputs,16-bit noise LFSR,11-bit noise counter, divider, stereo mask/detection controls and audio release phase. This PSG has no separate envelope generator. Several declared `last_out`, `v`, and `update` values are unused, not omitted operational state.

Actual path: JT89 ss_out low52 -> legacy word00e/018; ss_ext_out96 ->021/022 (PSG2->023/024); clk_div and phase -> descriptor020. Word00e bit63 is the extension presence marker and bits62:52 hold audio controls. Save first invalidates that marker, writes data/descriptor, drains, then commits it. Loader only inspects extension metadata if marker is present; descriptor validates magic50534758, version1, System E mode, word count2/4 and reserved bits. Payload upper32 of each high half must be zero. Modern restore applies configuration/ext/control with enables frozen, and release restores AudioMix phase. Older unmarked files retain historical configuration-only behavior and cannot reproduce the missing oscillator/noise phase.

`psg_replay_tb.sv` uses **unmodified production JT89/tone/noise/volume/mixer** instances. Both receive nontrivial tone and volume writes. After warm-up it selects each divider phase, captures at quiescence, advances DUT4099 enabled clocks while reference holds, restores configuration/ext/divider, permits four pipeline settling clocks, and compares full config/ext/divider and stereo output every cycle for20,000 clocks. All **128 cases (8 noise controls x16 divider phases), 2,560,000 compared cycles passed**. It verifies actual counters/LFSR/raw sample state, not mere register readback. It is a subsystem replay; its direct load interface does not exercise DDRAM transfer, AudioMix's separate toggle, arbitrary subsequent PSG writes, tone<6 sample-playback cases, or System E integration. Earlier `tests/psg_resume_contracts/build/results.csv` has zero PSG and Contract-B mismatches in the inspected rows, but Contract-A mismatches; these are historical artifacts, not freshly reproduced evidence or proof that current full integration passes.

Accordingly **PSG oscillator/noise coverage is complete with justified quiescence/reconstruction exclusions for modern snapshots; whole-core, both-PSG/audio-release integration still needs further evidence**. No new PSG omission was found. This does not make legacy files exact, nor close the independent FM gap. The two PSGs share divider state only under the existing synchronization assertion; that assertion must be exercised in System E replay before global signoff.

## Verification, reproducibility, and closure

New tests: ModelSim-Altera10.5b compiled current production `io.vhd`, `eeprom_93c46.vhd`, `sega_controller.sv` and JT89 hierarchy. Three defect reproductions passed their expected-divergence assertions; PSG replay passed all128 cases. Directed fixtures apply the same exposed state interfaces used by the controller, **not** full CPU/DDR savestate transactions. EEPROM test snapshots mid-command and restores DUT while reference continues; it proves loss without needing extra perturbation. MD6 test shortens TIMEOUT_CYCLES to64 and holds reference clock; it demonstrates protocol loss, not a full80540-cycle integrated save. GG PDR test uses actual write/read ports and actual io_state vector. No FM, full-machine, encrypted-System E, random-stall memory, or physical cable replay was newly run.

The first GG fixture attempt left DDR as inputs and failed its expected readback; fixed setup explicitly drives DDR=0. Final `simulation.log` is the successful run. ModelSim2388 was suppressed for JT89's existing forward implicit-net/redeclaration of cen_16; no source rewrite was used.
