Perform Register Retiming for Performance logic option Perform Register Retiming for Performance logic option A logic option that directs the Fitter to perform physical synthesis optimizations on registers, specifically allowing register retiming, during fitting to increase circuit performance. This option is available for all Altera devices supported by the Quartus ® Prime software except MAX3000 and MAX7000 devices.
