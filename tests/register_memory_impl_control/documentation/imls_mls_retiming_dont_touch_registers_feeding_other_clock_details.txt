ID:13099 Not allowed to move at least <number> registers because they feed registers in a different clock domain List of Messages Parent topic : List of Messages ID:13099 Not allowed to move at least <number> registers because they feed registers in a different clock domain CAUSE: You attempted to optimize netlists by directing the Quartus Prime software to perform gate-level register retiming. However, the Quartus Prime software cannot move the specified number of registers because they feed the data, clock enable, or synchronous control signals of registers in a different clock domain. The number of registers reported in this message may be lower than the actual number of registers feeding registers in a different clock domain, because some registers may not be allowed to be moved for other reasons. ACTION: If you want to allow the Quartus Prime software to move these registers, set the Netlist Optimizations logic option to Always Allow . Otherwise, no action is required.
