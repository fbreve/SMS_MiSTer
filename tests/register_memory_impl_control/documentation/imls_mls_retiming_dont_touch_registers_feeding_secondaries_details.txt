ID:13100 Not allowed to move at least <number> registers because they feed clock or asynchronous control signals of other registers List of Messages Parent topic : List of Messages ID:13100 Not allowed to move at least <number> registers because they feed clock or asynchronous control signals of other registers CAUSE: You attempted to optimize netlists by directing the Quartus Prime software to perform gate-level register retiming. However, the Quartus Prime software cannot move the specified number of registers because they feed clock or asynchronous control signals of another register. The number of registers reported in this message may be lower than the actual number of registers feeding asynchronous control signals, because some registers may not be allowed to be moved for other reasons. ACTION: If you want to allow the Quartus Prime software to move these registers, set the Netlist Optimizations logic option to Always Allow . Otherwise, no action is required.
