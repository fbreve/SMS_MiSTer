# Sequential snapshot-transfer invariant

The first routed implementation used indexed64-bit reads and indexed64-bit writes into two4,800-bit snapshot registers. It failed routing at39,680/41,910 ALMs needed; memory remained487 M10K /3,809,858 bits. The correction changes only private transport representation, removes the now-unread old alignment-timeout declaration/assignments, and keeps v14 bits, addresses, transaction timing, CPU/VDP/PSG holds and canonical release unchanged. No seed, constraints, device or guest timing offset changes.

Write a padded captured record as75 words B[0]..B[74], least significant first. After k successful SAVE writes, the rotating buffer has low word B[k mod75]. Each successful write transmits that low word and rotates it to the top. Busy clocks neither transmit nor rotate. After75 writes the buffer is exactly the captured record again. Bank selection changes only after its75th write, so the next bank starts unchanged. The75 constant is the payload's word count, not a guest execution delay.

On LOAD, each accepted word W[k] shifts into the high64 bits and the old buffer shifts down64. After75 accepted words, bits64i+63:64i equal W[i] for every i=0..74, independently of the old scratch contents and DDRAM stalls. The original descriptor, owner, reserved-bit and last-word22-bit padding checks run before the same state transitions. Both physical4778-bit records, including all inactive cache bits, are preserved. Legacy clearing is unchanged.

The continuously exposed sprite restore bus can differ during transport because its private scratch representation rotates. Production VDPs consume that bus only when ss_regs_set is asserted. That strobe occurs after all75 words of each bank have been collected. It is never asserted while a SAVE rotation or partial LOAD is in progress. All other outputs and the FSM state are cycle-identical.

`transport_equivalence` instantiates the failed indexed controller and the new sequential controller on the same inputs and checks all151 ports'91 outputs plus the FSM state. Only the two sprite data buses are compared at their consuming VDP restore strobes; neither image fields nor DDRAM transactions are masked. It reruns185 inherited format tests, then16 metadata combinations (four phases × two ownership modes × two capture-consumption values), with randomized full-width records, DDRAM busy/response delays, three LOADs per image and complete image immutability. Every transmitted word and both restored physical records are also checked against independent padded-record arrays. This is a protocol-equivalence proof boundary, not an assertion that every randomized metadata combination is naturally capturable.

The actual64-slot distinct-Q replay and CPU/NMI/Pause matrices are additionally rerun with the new controller. Earlier sprite/phase/dual-device proofs remain applicable because their device inputs, strobes, clock enables and consuming payload values are unchanged cycle for cycle. The existing50,000-clock output-alias proof covers the separate VHDL language-compatibility correction. Neither transport optimization adds historical state or changes the v14 format.
