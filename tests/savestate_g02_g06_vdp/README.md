# Reproduction

Run from the repository root using Windows PowerShell, Node and the existing ModelSim17.0 vendor library installation. No Quartus is used.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/savestate_g02_g06_vdp/run.ps1 -Compile -Reference 1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/savestate_g02_g06_vdp/run.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/savestate_g02_g06_vdp/control.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/savestate_g02_g06_vdp/control.ps1 -Sprites 9
& 'C:/Program Files/nodejs/node.exe' tests/savestate_g02_g06_vdp/inventory.js
& 'C:/Program Files/nodejs/node.exe' tests/savestate_g02_g06_vdp/analyze.js --final
```

The reference must finish before the DUT consumes reference.dat. Main reference/DUT and the one-sprite pair use separate working directories. The shared compiled library is read-only during runs. The current fixture uses supported turbo /10 CPU cadence; /15 experiments are retained as pilots, not admitted as isolated VDP evidence.

The main DUT intentionally characterizes a collision/status difference rather than aborting at its first sample. `analyze.js --final` requires three completed nonzero-divergence LOAD results, a completed zero-divergence one-sprite control, nine-sprite SAVE-only overflow and reference-relative CPU/RAM differences, known complete v13 image,16384 exact initialized active-bank VRAM bytes, and unchanged production/index. A DONE marker alone does not prove successful equivalence. The image is generated by the current writer and consumed by its current reader; the900000-clock flush and raw-video release alignment are unchanged.

The observer adapter only exports a32-bit probe; production VDP/background/sprite/CRAM/RAM behavior is unchanged. The controller simulation adapter moves three pre-existing forward declarations. CPU adapters qualify direct VHDL entity bindings. `header.svh` supplies current controller ports and deterministic idle peripheral endpoints; this is not a whole-board peripheral or SDRAM/decryption model.

Reference captures1000 known native-pixel observations from an independent uninterrupted execution. SAVE-only compares135 VDP bits and RGB, plus exact beam alignment. Bit119 line_overflow is retained as an explicit internal diagnostic under a <=2-sprite/inactive-overflow-source guard; review.md explains why it is not counted as guest divergence here. LOAD scores the collision flag and real status-read bus against the reference at the same x/y. CPU historical T1/T2 is permitted as already defined by v13; no claim is made that all cross-chip /15 phases or all IRQ handlers have been proven.

Other F/G suites are not rerun or claimed closed.
