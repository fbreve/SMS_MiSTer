# F15 implementation contract

Read the complete authoritative investigation before production edits. Baseline `ff9d66b`, branch `fix/savestate-evolution-pending` (the existing branch was verified to point at F14, then selected).

Preserve three live reset-zero bits: `switch_armed` (first post-3FFE falling M1 arms; next falling M1 consumes), `record_read_pending_r` (menu-context falling M1 at1380 recognizes; next non-M1 MREQ/RD memory read consumes), `menu_launch_armed_r` (recognized data read sets; next recognized game commit consumes). All updates run on enabled host clocks, independent of CPU CE. All three survive accepted fetch captures, independently and in combination; v10 LOAD clears them.

Lost armed state prevents the future command commit, so the production T80 resumes through Flash008123/data00 rather than288123/data28. Lost read-pending prevents capturing the record address and changes a future mapping. Lost menu arm suppresses the future launch pulse/bank reset despite exact restored F14 state and saved banks. Preserve their exact saved-time values, never current Q state.

Do not preserve `switch_pending`: the first falling M1 consumes it before production T80's qualifying MREQ-low fetch CE. Restore it to0. Reconstruct `old_m1_n` as0, the restored T80 opcode-fetch level; transient `game_launch_r` was already consumed before acceptance and remains a one-clock output, not a saved pending bit. F14's57 existing bits and pending command8 remain unchanged. No unique reconstruction or bounded full-protocol capture deferral is established; menu arm/read-pending can persist indefinitely. No stronger full-T80 collision proof is required or claimed.

A permanent launch-timing assertion reproduced this even though mirrored ROM still returned28 later. Wire existing `ss_freeze` into Evolution, hold ordinary bus observation while frozen (restore/reset still have priority), and hold reconstructed old-M1=0 through CPU restart. Guest launch must occur once at target0020 after release. This is required to satisfy the authorized F15 semantic timing contract, not a general Evolution refactor. Save-only equivalence is rechecked with the freeze connection.
