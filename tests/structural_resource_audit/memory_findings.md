## Positive inference controls and inactive helpers

`spram`/`dpram`/`sprom` instantiate synchronous memories for WRAM, NVRAM, VRAM, BIOS/boot/key storage. Gamma768×8, HQ2x600×96 and300×24 buffers, OSD4096×8 per output, scaler line/coefficient/palette memories, shadowmask256×11 and inferred delay memories all appear in the fitted RAM table. Some very short/wide delays consume multiple blocks because width/port organization, not bit count alone, governs allocation.

`rtl/parts.v` contains additional2K/4K/VRAM/SPRBUF helper definitions; only the two instantiated128-entry decryption tables appear in current fitted RAM inventory. `rtl/compressor.sv` contains a2,048×15 constant lookup wire array, but no compressor instance is present in the fitted hierarchy. Similarly source-only MT32 LCD1024×8 storage and alternate gamma-channel definitions must not be charged without an active hierarchy. The scanner indexes declarations, not instantiated utilization. Check [hierarchy.json](hierarchy.json) and [ram_inventory.md](ram_inventory.md) for the actual configuration.

The production VDP background is discrete139-bit historical pipeline state per VDP, not a large failed-RAM array. Its shifts, addresses, tile bits and decode have simultaneous consumers. Mapper/Evolution state consists of small protocol/bank/history registers; bulk cartridge contents already use SDRAM/M10K. Neither supplies evidence for another hidden multi-kilobit fabric RAM.
