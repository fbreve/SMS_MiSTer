# F09 design and isolation

Base e4a1ac9, branch fix/savestate-master-tap. Production is still unchanged at this design checkpoint. Before fixtures extract the actual accessory always block from baseline/SMS.sv; threshold replacement is test-only. Both threshold 8 and actual threshold 57000 give 53 divergences in 64 phase/TH/boundary cases. Identical held reference is resumed for future inputs; only the DUT experiences transport/progress. The before test applies ce_cpu every fixture clock to exercise the production counter value; full-DDRAM tests must additionally use the real one-in-15 enable cadence.

The audit row is S072 in the current CSV (the request calls it S071); this is the same named F09 Master Tap omission, not a scope change.

Persistent state is exactly 19 bits: tmr[15:0], jcnt[1:0], old_th. jcnt indexes the four players for port A. Port B is FF while Master Tap is enabled; there is no second Master Tap instance. Timer counts only while TH is high on raw ce_cpu, stops at 57001, and resets phase when its old value is greater than 57000. Falling TH clears timer; it advances the phase only when old tmr is less than 57000. Thus the boundary at 57000 deliberately ignores the first falling edge after discharge. old_th is independent pending-edge history. The shared timer is also used for the raw-serial pause-combo countdown; it is a single local register, not external controller hardware. Capture/restore this actual register, without splitting or changing its ordinary cross-mode behavior. Its temporal updates are suspended during transport in both existing branches so one register cannot mutate behind the saved image. Physical pins, joystick buttons, swap/accessory configuration and host keyboard state remain current inputs.

No mode-history register or cached player vector exists. joya/joyb/joyser, TH return and USER_OUT are registered derived pin caches: after restoring the phase and current inputs, they reconstruct on subsequent host clocks, before the existing 255-cycle release guard permits guest execution. They are not additional independent protocol state. Master Tap and MD pads are configuration-exclusive: md_pad_enable includes !status[14] and excludes raw serial. F08 pad state transport and clocking remain unchanged. Paddle/lightgun override branches are preserved verbatim.

Legacy normalization is jcnt=0, tmr=57001 (expired/saturated), old_th=current restored joya_th_out. This follows the actual idle/discharged state and avoids inventing either a TH edge or a first-edge player advance. Zero timer is not equivalent: it would advance player on the first falling edge. Normalize late at pre-unfreeze after IO TH restoration settles. Ordinary reset outside savestates still resets only jcnt as before; no new reset semantics or power-up initialization is added.

Use v6 tag 484306, unchanged base payload count 3. Old v1/v2/v3/v4/v5 tags stay explicitly supported. A new word 026 contains {13'd0, old_th, jcnt[1:0], tmr[15:0], 32'h4d544150} (MTAP). Loader consumes it only under validated v6 tag/count, exact magic, zero reserved bits and timer <=57001. Old snapshots never consume word026. Invalid or unsupported metadata normalizes as legacy. Old 64KiB load path must explicitly clear validity. Existing HCounter, GG, MD6, EEPROM, SC descriptor/data and PSG positions do not move; word026 follows descriptor025 and precedes EEPROM030/031. Slot stride remains 3000; no new RAM is allocated.

Capture after freeze is active and drain has completed, matching the accessory accepted frozen instant. Restore once at pre-unfreeze. Hold timer/TH progress during transport; state restoration takes priority over the hold. Raw ce_cpu generation and all normal controller timing are unchanged. Shared local-timer restoration is the only serial-side consequence; no physical serial state or new pause protocol is introduced.
