# G09.last-read production contract

HEAD: faf7036e4450027f79cc639a731053dca29840ca. The three production textual occurrences are all in rtl/mapper_ctrl.vhd.

| Location | Meaning |
|---|---|
| 96 | `signal last_read_addr : std_logic_vector(15 downto 0);` No initializer |
| 306 | The only assignment: `last_read_addr <= A;` |
| 447 | The only consumer: `if last_read_addr /= x"A000" then`, enclosing `if mapper_codies='0' then bank2 <= D_in; end if;` |

No reset assignment exists. The asynchronous RESET_n=0 branch resets banking and edge trackers but leaves this signal untouched; it is U until first assignment in RTL simulation, and retains its previous value across subsequent reset assertion. Neither zero nor A000 is an architectural reset value. There is no v12 field, output or restore assignment for this latch. Observation ports in this investigation do not feed back.

The effective sole update condition is rising clk_sys, RESET_n=1, mapper_set=0, ce_z80=1, WR_n=1, MREQ_n=0. It does **not** check RD_n, M1_n, mapper type, address range, bootloader_n or ss_freeze. It can sample refresh as well as a memory read. Top-level transport suppresses the enables supplied to system, and system uses the same ce_z80 for T80 and mapper_ctrl. Therefore it holds during ordinary global transport despite lacking a local freeze term. Independently stimulating mapper_ctrl with ce_z80 high while frozen is a different interface contract.

The dependent guard is under the final generic branch of the mapper priority chain. That branch is bypassed by active Janggun, EEPROM, System E/SC/Castle/linear/Dahjee/Sega-locked, 4PAK, active Zemina, and the eligible first-4PAK trigger. Within the generic branch, the A000 case additionally requires ss_freeze=0, WR_n=0, MREQ_n=0, nvram_e=0, mapper_lock=0 and mapper_codies=0. This write path is evaluated on every host clock, not only ce_z80. In particular, the System E cadence changes CPU frequency but its generic dependent consumer is structurally bypassed. Janggun's separate A000 bank4 case does not consult last_read_addr.

Detection does not read last_read_addr. It independently tracks eligible writes/evidence and selects the priority path; bootloader/Wonder Kid edges can initialize banks, not the latch. Generic A000 handling itself has no additional bootloader_n requirement. Wonder Kid may reach it when the remaining gates permit; boot visibility and history must not be conflated with the latch. F13's reconstructed edge trackers and its saved 18-bit detector history remain separate.

Causal chain: a qualified CPU memory or refresh sample captures **logical** A. A later generic A000 write either suppresses bank2 when that saved logical address is A000 or assigns D_in otherwise. memory_decode uses bank2 for the 8000-BFFF ROM window, changing physical mapped address and CPU data. The latch does not affect the read which reconstructs it, nor any restore input, read data mux, CPU enable or bus strobe.

## Reconstruction proof

1. A naturally accepted SAVE requires a CPU enable with M1=0, MREQ=0 and ISet=00. In the production T80s normal eligible MC1/T2 memory fetch, WR=1, RD=0. The accepted CPU image is pre-T2 architecture. Mapper_set is not active at acceptance. On that same clock the mapper samples the fetch A; let this deterministic logical address be F. Thus the uninterrupted **post-acceptance** latch is F, even when the pre-edge latch was some different prior operand/refresh address.
2. The next-clock freeze prevents another guest enable. The updater cannot create a bank write: its WR=1 qualification and the dependent consumer's WR=0 qualification are mutually exclusive. Capturing or not capturing the overwritten pre-edge latch cannot change post-T behavior.
3. LOAD restores the mapper before the CPU. Global freeze prevents dependent writes. Mapper_set does not consume the latch and explicitly skips its update branch. DIRSet canonicalizes T80 to MC1/T1 and sets WR/MREQ/RD/IORQ high in the wrapper. Therefore a stale Q latch has no dependent consumer during restore, guard time or the beginning of CPU preparation.
4. F16 installs temporal NMI state with CEN=0, then performs normal-rate CPU-only T1 setup and historical T2. T1 starts the memory fetch at F, setting MREQ=0 and RD=0 while WR remains1. At the following native ce_z80, the mapper reads those pre-edge levels and assigns last_read_addr=F. This is exactly the original accepted T2 update, not an inferred value from the later Q timeline. Mapper_set has ended well before this edge. A WAIT extension merely adds qualifying reads; it cannot enable a write first.
5. No dependent A000 write can precede that read: WR was canonicalized high, T1/T2 are memory-fetch setup/replay, and ordinary write strobes are generated only by later guest microcycles. A selected NMI still has the mandatory dummy memory fetch before stack writes; even a stack write at A000 cannot precede reconstruction. Maskable interrupt acknowledge does not satisfy the accepted MREQ-low fetch predicate. HALT's repeated fetch, an unconsumed prefix opcode, and an accepted block-repeat fetch all share the same wrapper ordering. This is an ordering argument for this latch, not a proof of every CPU microstate's restart correctness.
6. After T2, every future use depends only on F and subsequent qualified logical bus samples. Replaying those samples deterministically recreates the same last-read value; no subsequent consumer can recover or consult pre-reconstruction Q. Mapping changes affect physical ROM addresses but not this logical-A assignment. BIOS/Wonder Kid branch changes and F13 edge settling likewise add no hidden last-read consumer.

This is a dataflow/reconstructability proof, not an injective-format claim. Complete images can omit an overwritten cache. A candidate pair with equal saved architecture but different pre-acceptance latches is normalized by the accepted fetch itself; a candidate difference retained through LOAD is erased by the corresponding replayed fetch before it can affect banking. No complete current-v12 identical-image pair with divergent future caused by this latch has been established. General CPU restart equivalence is a separate obligation and is not certified here.
