# Slot-counter candidate and compatibility argument

The candidate changes only `rtl/VM2413/slotcounter.vhd`. All 100 state words, read/write addresses, descriptor, format validation, transport, initialization and legacy defaults remain unchanged. There is no lossy state reduction.

For seven-bit input x and instantiated delay d in {0,2,5,8}, the reference restores `(x-d) mod 128` when x>=d and `(x+72-d) mod 128` otherwise. The candidate selects the corresponding seven-bit constant `(128-d) mod 128` or `72-d`, then performs one seven-bit sum. These equations agree for every x in 0..127, including values beyond the valid counter range. For valid x in 0..71 this is the required `(x+72-d) mod 72` relationship. The new temporary offset is fully assigned before use and adds no architectural state.

The exhaustive simulation instantiates separately compiled candidate and exact-reference counters at all four actual delays; it checks all 128 inputs against an independent arithmetic result, all 256 addresses, concurrent read/write, hold, normal running, stopped enable and reset. Every sampled counter output and response must match. Other controls and sequential updates are unchanged, so the local equivalence composes with arbitrary interrupted apply sequences: the same word-78 write makes exactly the same update, and an interrupted transaction that never writes word 78 makes no new update.

The independent existing Tcl oracle separately packs all 100 live words from RAM, signals and process variables, without reading the serializer. Eight pattern images verify every word, and the reused live suites check saved DDR data and restored state. The additional strict test restores both reference and candidate from the same state after the same future and compares every host clock, including the already-unsaved mixer's immediate post-LOAD output. It does not exclude a settling window. Seventy-two repeated save/load pairs exercise changing musical activity; this count is not a claim that all 72 capture counter positions are distinct.

The existing main continuation suite retains the production 900000-host-clock flush. Additional mode/phase matrix runs use the existing 90-clock test adapter and NCONT=5000, and are explicitly identified as such. Neither these synthetic cases nor the local equivalence test is presented as new game/hardware audio qualification.

The existing atomicity regression checks malformed-load rejection and a late DDR timeout. The reference allows partial VRAM updates before a late timeout; the patch preserves that behavior and does not claim transactional rollback. The exact FM reference predates the qualified Ys SRAM correction; this experiment does not integrate or alter that correction.

Portability adapters apply identically to both simulation libraries: VHDL-2008 reserved identifier rename, scalar subtype range expansion, null nonbinary case alternatives, and labels for process-variable inspection. The template wrapper's unused `verify_word_76` debug assignment is removed; the independent oracle reads the actual wrapper bus. Savestate declaration ordering is adjusted only in simulation copies. Failed wrapper-debug and VHDL-concatenation compilation attempts are retained separately; they were harness preparation errors, not failed candidate functional tests.
